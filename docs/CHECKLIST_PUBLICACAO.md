# Checklist de publicação

- [ ] Confirmar domínio definitivo em `VITE_SITE_URL`.
- [ ] Confirmar número do WhatsApp, CRM e RQE.
- [ ] Confirmar que avaliações/depoimentos publicados são reais e autorizados.
- [ ] Configurar GTM ou GA4.
- [ ] Se usar Google Ads direto, configurar Conversion Label.
- [ ] Testar aceitar, rejeitar e alterar preferências de cookies.
- [ ] Testar `whatsapp_click` em Hero, Header, Médico, Sinais e CTA final.
- [ ] Conferir `utm_source`, `utm_medium` e `utm_campaign` em uma URL de teste.
- [ ] Conferir o código de atendimento incluído no WhatsApp.
- [ ] Rodar `npm run validate:production`.
- [ ] Rodar `npm run build:production` quando os IDs finais estiverem configurados.
- [ ] Testar desktop e celular após o deploy.
